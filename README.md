# Бюджет для двоих

Приватное веб-приложение для совместного управления семейным бюджетом двух участников.

## Возможности

- Доходы и расходы с категориями и автором операции
- Счета и балансы
- Финансовый календарь
- Регулярные платежи с ручным подтверждением
- Бюджеты по категориям
- Финансовые цели и история пополнений
- Планируемые покупки
- Месячное планирование и сравнение плана с фактом
- Отчёты и экспорт CSV
- Анализ доходов и расходов по участникам
- Уведомления
- Адаптивный интерфейс для компьютера и телефона

## Технологии

- React 18, TypeScript, Vite
- Tailwind CSS, React Router v6
- Google Sheets — хранение данных
- Google Apps Script — API и авторизация

## Локальный запуск

```bash
npm install
cp .env.example .env
```

В `.env` укажите URL опубликованного Apps Script Web App:

```env
VITE_GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/DEPLOYMENT_ID/exec
```

Затем запустите:

```bash
npm run dev
```

## Настройка backend

- Инструкция: [google-apps-script/SETUP.md](google-apps-script/SETUP.md)
- Исходный API: [google-apps-script/Code.gs](google-apps-script/Code.gs)
- Текущая версия API в репозитории: **10**
- Переменная фронтенда: `VITE_GOOGLE_APPS_SCRIPT_URL`

Таблица Google Sheets должна оставаться закрытой для публичного доступа. Веб-приложение Apps Script выполняется от имени владельца таблицы; доступ к операциям контролируется собственной авторизацией приложения.

## Статус выпуска

- Интерфейс и адаптивная навигация обновлены; владелец проекта проверил внешний вид Preview.
- Ветка выпуска: `work/final-features-performance`. Последняя проверенная сборка сайта проходит Vercel; регрессионные проверки выполняются через GitHub Actions.
- Preview основного Vercel-проекта использует отдельную тестовую таблицу. Не вводите туда реальные финансовые данные.
- Production сайта не переключать до подтверждения источника уже внесённых данных и их резервного экспорта.
- Telegram: готова страница привязки, одноразовые коды, Apps Script webhook-обработчик и отдельный Vercel endpoint. Для запуска ещё нужны секреты, обновление тестового Apps Script до API v10 и сквозная проверка.
- API v10 автоматически добавляет только отсутствующие конечные столбцы, если существующая структура является точным префиксом; две служебные Telegram-таблицы создаются при первом обращении.

Суммы хранятся в копейках. Регрессионные тесты не заменяют проверку реального Apps Script, двух пользовательских аккаунтов и изоляции данных разных семей.
