# Бюджет для двоих

Веб-приложение для совместного управления семейным бюджетом на двоих. Существующий React-интерфейс сохраняется; для этой ветки готовится переход на Google Sheets + Google Apps Script.

## Возможности интерфейса

- Доходы и расходы, категории и автор операции
- Финансовый календарь
- Регулярные платежи с ручным подтверждением
- Бюджеты по категориям
- Финансовые цели и история пополнений
- Планируемые покупки
- Месячное планирование и сравнение плана с фактом
- Отчёты и экспорт CSV
- Анализ доходов и расходов по участникам
- Уведомления
- Telegram-бот — возможное отдельное расширение

## Технологии

- React 18 + TypeScript + Vite
- Google Sheets для хранения данных
- Google Apps Script как API
- Tailwind CSS, React Router v6

## Локальный запуск

```bash
npm install
cp .env.example .env
# В .env укажите URL опубликованного Apps Script Web App
npm run dev
```

## Настройка Google Sheets

Инструкция находится в [google-apps-script/SETUP.md](google-apps-script/SETUP.md). Код API — в [google-apps-script/Code.gs](google-apps-script/Code.gs).

Переменная окружения фронтенда: `VITE_GOOGLE_APPS_SCRIPT_URL`.

## Статус миграции

Работа выполняется в ветке `migration/google-sheets`; ветка `main` и опубликованный сайт не переключены на новый backend. Это начальная реализация. До использования реальных финансовых данных нужно проверить авторизацию, семейные приглашения, CRUD-операции, работу двух пользователей и изоляцию данных разных семей.

Суммы хранятся в копейках. Веб-приложение Apps Script должно выполняться от имени владельца таблицы; саму таблицу нельзя делать публичной.
