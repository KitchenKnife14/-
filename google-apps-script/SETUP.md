# Подключение Google Sheets

## 1. Подготовить Apps Script

1. Откройте таблицу Google Sheets **«Семейный бюджет»**.
2. Выберите **Расширения → Apps Script**.
3. Откройте `google-apps-script/Code.gs` в этой ветке GitHub, скопируйте весь код и замените содержимое `Code.gs` в редакторе Apps Script.
4. Сохраните проект.

Листы приложения создаются автоматически при первом обращении. Лист `_auth` хранит записи авторизации и автоматически скрывается. Не публикуйте саму таблицу и не выдавайте доступ к ней всем пользователям.

## 2. Развернуть веб-приложение

1. В Apps Script нажмите **Развернуть → Новое развертывание**.
2. Тип: **Веб-приложение**.
3. Выполнять от имени: **вас** (владельца таблицы).
4. Доступ: выберите вариант, при котором веб-приложение может получать запросы от браузера. Доступ к данным должен контролироваться кодом API, а не публичным доступом к самой таблице.
5. Разверните и скопируйте URL, заканчивающийся на `/exec`.

## 3. Подключить сайт

1. В Netlify откройте настройки сайта → **Environment variables**.
2. Добавьте `VITE_GOOGLE_APPS_SCRIPT_URL` со значением URL `/exec`.
3. Запустите новое развертывание сайта.

Для локального запуска создайте `.env` по примеру `.env.example`.

## Важно перед использованием

Это первая реализация миграции, её ещё нужно проверить в развернутой среде: регистрация, вход, создание семьи, приглашение второго участника, чтение/изменение/удаление операций и изоляция данных разных семей. Пока эти проверки не пройдены, не переносите сюда реальные финансовые данные. После каждого изменения `Code.gs` создавайте новую версию веб-развертывания Apps Script.
