# Family Cash — список будущих улучшений

Этот список содержит идеи, которые можно реализовать после завершения основных макроэтапов и стабилизации текущего приложения. Это не обязательства и не часть текущей приёмки. Приоритеты можно пересматривать; ничего из списка не должно задерживать исправление ошибок и завершение текущего плана.

## Возможные функции

| Идея | Что даст | Статус |
|---|---|---|
| AI-помощник по семейным финансам | Отвечать на вопросы о расходах, доходах, бюджетах и целях на основе данных семьи | Отложено |
| Автоматическая категоризация операций | Предлагать категорию по описанию и истории похожих операций | Отложено |
| Поиск необычных расходов | Показывать заметные отклонения от привычных расходов | Отложено |
| Прогноз бюджета до следующей зарплаты | Оценивать остаток доступных денег и ожидаемые обязательные платежи | Отложено |
| Голосовой ввод операций | Добавлять доходы и расходы голосом с подтверждением перед сохранением | Отложено |
| Напоминания об автоплатежах | Напоминать о регулярных платежах и приближении даты списания | Отложено |

## Условия реализации

- Сначала завершить основные макроэтапы и закрыть обязательные исправления.
- Не подключать нейросети и внешние платные сервисы без отдельного решения пользователя.
- Предложения нейросети по операциям и категориям показывать пользователю для подтверждения перед записью.
- Не менять существующие финансовые записи и алгоритмы балансов ради добавления необязательных функций.
- Учитывать ограничения проекта: Google Sheets + Apps Script + Vercel + GitHub; Supabase не использовать.

## Приоритет

Список не является очередью обязательных работ. После стабилизации и выпуска сайта приоритет среди новых функций — интеграция нейросети для семейного бюджета. Восстановление пароля можно реализовать раньше только если это станет практической необходимостью и не будет мешать завершению текущего плана.
